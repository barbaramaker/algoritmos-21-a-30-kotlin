# Algoritmos 21 a 30 em Kotlin

Este repositório contém os algoritmos 21 a 30 do livro *Introdução à Programação: 500 Algoritmos Resolvidos*, de Anita Lopes e Guto Garcia, convertidos para Kotlin.

O objetivo da atividade é praticar a linguagem Kotlin e compreender o funcionamento de diferentes operações e comandos de programação.

## Algoritmos desenvolvidos

**Algoritmo 21 — Testando Hierarquia**  
Testei a prioridade dos operadores matemáticos e utilizei parênteses quando necessário para manter os resultados do algoritmo original.

**Algoritmo 22 — Testando Hierarquia**  
Trabalhei com operações de divisão, resto e arredondamento, observando as diferenças entre os operadores do livro e os do Kotlin.

**Algoritmo 23 — Algarismo das Dezenas**  
Desenvolvi um programa que recebe um número de três algarismos e identifica o algarismo da casa das dezenas.

**Algoritmo 24 — Algarismo das Dezenas**  
Utilizei divisão inteira e resto da divisão para encontrar o algarismo das dezenas, corrigindo a ordem das operações apresentada inicialmente no livro.

**Algoritmo 25 — Separando uma Data**  
Criei um programa que recebe uma data no formato DDMMAA e separa o dia, o mês e o ano.

**Algoritmo 26 — Alterando o Formato de uma Data**  
Desenvolvi um programa que recebe uma data no formato DDMMAA e reorganiza seus valores para MMDDAA.

**Algoritmo 27 — Incremento e Decremento**  
Utilizei os operadores `++` e `--` para aumentar e diminuir os valores de duas variáveis.

**Algoritmo 28 — Exibindo uma Mensagem**  
Criei um programa que imprime uma mensagem no console utilizando `println()`.

**Algoritmo 29 — Imprimindo o Nome**  
Desenvolvi um programa simples para exibir meu nome na tela.

**Algoritmo 30 — Produto entre Dois Números**  
Calculei e imprimi o resultado da multiplicação entre 28 e 43.

## Linguagem utilizada

- Kotlin

## Ambiente de desenvolvimento

- IntelliJ IDEA

## Observações

Mantive os pseudocódigos originais como comentários nos arquivos para facilitar a comparação com as versões em Kotlin.

Em alguns algoritmos, precisei adaptar a prioridade dos operadores e o comportamento das divisões para reproduzir os resultados apresentados no livro.
